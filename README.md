# Site Kerrou

## Description

Le site Kerrou est une page d'accueil moderne et élégante conçue pour présenter une marque de mode ou de vêtements. Il met en avant un slogan accrocheur "Wear your story" avec un appel à l'action pour découvrir la boutique. Le design comprend :

- Un en-tête avec un logo et une navigation menant vers les pages principales (Home, Shop, Contact, About) sur un site externe (Squarespace).
- Une section héros centrée avec du texte stylisé et un bouton "SHOP NOW".
- Une vidéo en arrière-plan qui joue automatiquement en boucle pour un effet immersif.
- Un style responsive avec des effets de survol et des ombres pour une apparence premium.

Le site est entièrement statique, utilisant HTML, CSS et des ressources multimédias (images et vidéo).

Pour cloner le code source et travailler localement, utilisez la commande suivante :

```bash
git clone https://github.com/juldonnis-rgb/site_kerrou.git
```

Ensuite, ouvrez `index.html` dans votre navigateur pour voir le site.

## Technologies utilisées

- **HTML5** : Structure de la page.
- **CSS3** : Stylisation et animations.
- **Ressources** : Images (logo.png, banniere.png) et vidéo (video.mp4).

## Déploiement

Le site est déployé via GitHub Pages. Pour le déployer sur votre propre compte, poussez le code vers un dépôt GitHub et activez Pages dans les paramètres du dépôt.
